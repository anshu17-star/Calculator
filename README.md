# 🧮 Basic Calculator

A simple and responsive **Calculator Web Application** built using **HTML, CSS, and JavaScript**.
It performs basic arithmetic operations along with percentage calculation and provides useful controls like clear and backspace.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 📊 Percentage calculation
* 🔄 Clear (`C`) button
* ⌫ Backspace button
* 🔢 Decimal number support
* 📱 Simple and responsive user interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and layout
* **JavaScript** – Calculator logic and functionality
